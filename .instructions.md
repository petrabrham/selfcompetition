## Critical Setup Notes

### SSL/TLS Certificate Requirements (Corporate Network)
- **Issue:** Zscaler proxy intercepts HTTPS; Gradle cannot download dependencies without proper SSL configuration
- **Solution:** Merged PKCS12 truststore at `C:\Users\<username>\.gradle\gradle-merged-cacerts.p12`
- **Configuration:** `org.gradle.jvmargs` in `gradle.properties` files with custom truststore
- **Documentation:** See `doc/flutter-install-checklist.md` section 11

### Environment Variables (Required)
- `JAVA_HOME = C:\Program Files\Android\Android Studio\jbr`
- `PATH` must include `%JAVA_HOME%\bin`
- **Note:** Must be set at User level (Windows Environment Variables), not just in terminal

### Gradle Configuration
- **User-level:** `C:\Users\<username>\.gradle\gradle.properties`
- **Project-level:** `selfcompetition/android/gradle.properties`
- **Path format in gradle.properties:** Use forward slashes `/` even on Windows
- Example: `-Djavax.net.ssl.trustStore=C:/Users/username/.gradle/gradle-merged-cacerts.p12`

## Common Issues & Solutions

### Issue: `SSLHandshakeException: certificate_unknown`
- **Cause:** Zscaler proxy blocking Maven Central
- **Solution:** Ensure merged truststore created and gradle.properties configured
- **Check:** `./gradlew help --no-daemon` should succeed

### Issue: `ClassCastException: ApplicationExtensionImpl cannot be cast to AbstractAppExtension`
- **Cause:** Android Gradle Plugin version mismatch
- **Solution:** Regenerate Android files: `flutter create . --platforms=android --overwrite`
- **Note:** Does not affect Dart code in `lib/`

### Issue: Commands fail after opening new terminal
- **Cause:** Environment variables not set in new terminal
- **Solution:** Ensure JAVA_HOME set at Windows User level (not just in terminal)
- **Check:** Restart VS Code to pick up new environment variables

### Issue: `gradle.properties` path issues
- **Remember:** All paths must use forward slashes `/` in gradle.properties, even on Windows

## Development Workflow

1. **Feature Development:**
   - Modify `lib/` files
   - Use `flutter run` with hot reload for fast iteration
   - `flutter format` to maintain code style

2. **Dependencies:**
   - Add to `pubspec.yaml`
   - Run `flutter pub get`
   - Build may need full rebuild after pubspec changes

3. **Testing:**
   - Add tests to `test/` folder
   - Run: `flutter test`
   - Widget tests already exist in `widget_test.dart`

4. **Android-Specific Changes:**
   - Modify `android/app/build.gradle.kts` for Android config
   - Android-specific code goes in `android/app/src/main/java/com/example/selfcompetition/`
   - Run full `flutter clean` then `flutter run` after Android changes
